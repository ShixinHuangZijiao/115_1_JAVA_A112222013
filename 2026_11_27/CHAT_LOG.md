# 第八週與 AI 的討論過程

使用工具：Claude Code。

## 討論流程摘要

1. 我發現第四到七週的資料夾日期錯了，提供實際課表（10/09、10/23 放假，第五週 10/30、第六週 11/13、第七週 11/20、第八週 11/27）。AI 對照老師 GitHub 上傳教材的時間後改名更正，並記下課表，之後新一週會先確認日期。
2. 我說「開始做第八週的作業」。AI 先抓老師 GitHub 的最新版（老師當天下午剛補上第八週 AI_USAGE 範本），讀完投影片、examples、starter、ai 與範本圖，整理出 TODO 1–4、D5 邊界、E 段模擬 AI 審查、F1 UML 與課後遷移的規定；遷移題依建議選路線 A：SurveyRover。
3. 我要求「改完之後先不要 commit 上去」。AI 照做，並說明 E 段依規定要依序 `[AI]` → 預測 → `[fix]` 分次 commit，所以 E4 修正留到我檢查完、允許 commit 之後。
4. AI 依投影片建議的 1→2→3→4 順序完成 TODO，每做完一個就跑對應入口；B2、B3、C2 與 E3 的編譯錯誤實驗都在 repo 外副本進行。
5. AI 在 `experiments/` 寫 D5 邊界測試與反例，在 `transfer/` 寫 SurveyRover 與測試，並在副本植入錯誤確認反例抓得到；補 F1 類別圖並用 PNG 預覽檢查，最後寫 DESIGN、README、AI_USAGE、LAB_REPORT。
